# student-academic-performance-portal
This is a website where teachers can input the academic details of the students and students can track their academic performance at the same platform

#Problem Statement – Build a teacher-student portal where the teacher can efficiently manage the CT marks and also provide clean, easy and personalized records of CT performances to the students.

#Users and their role:
i) Teachers: Being the teachers, their role would be to manage CTs and enter the marks of students in their respective subjects. Also edit the marks in case of any error. Finally, do the overall calculation and make a class performance report.

ii) Students: Students will need to enter their college ID using which an OTP would be sent to their registered phone number which will help maintain privacy. Students can then access their profiles, CT-marks and overall performance. In case of any dissatisfaction regarding the marks in any subject, that student will have the option to raise a query in that particular subject which the teacher can review.

iii) HOD: HOD's role will be to examine the overall performances of classes to see if the students are actually learning the concepts. In case the average result is low, he/she can then take necessary steps.

#UI Flow:
Home Page → Login Page → Enter College ID → Receive OTP on registered phone → Enter OTP → Gain role-based access → HOD Dashboard / Faculty Dashboard / Students Dashboard
